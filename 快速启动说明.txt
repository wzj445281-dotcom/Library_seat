==========================================
  瑞幸咖啡后端启动说明
==========================================

后端启动可能遇到以下问题，请按步骤检查：

【问题1：数据库连接失败】
- 检查 MySQL 是否运行
- 检查数据库名称：ruixing 或 zhizuo
- 检查密码：默认是 "000000"
- 修改文件：seat_server/src/main/resources/application.yml 第20行

【问题2：Redis 连接失败】
- 如果没有安装 Redis，可以暂时注释掉 Redis 配置
- 或者安装 Redis for Windows

【问题3：端口被占用】
- 检查 8080 端口是否被占用
- 命令：netstat -ano | findstr :8080
- 如果被占用，修改 application.yml 中的端口号

==========================================
  手动启动步骤
==========================================

1. 打开新的命令行窗口（不要关闭）

2. 进入项目目录：
   cd E:\Coding\Wechat_project\bookSeats\seat_server

3. 启动后端：
   mvn spring-boot:run

4. 等待启动完成（看到 "Started ZhizuoApplication" 表示成功）

5. 在浏览器访问：
   http://localhost:8080/doc.html
